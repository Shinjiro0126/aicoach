# ホトリ トーンオブボイス・用語辞書

作成日: 2026-07-31

UI文言・AIプロンプト・通知文・ストア文言を書くときの基準。人格や世界観の原本は [brand.md](brand.md)、AI応答の口調の実装は `proxy/src/prompts.ts`。この文書は「言葉の運用」に特化する。

## 1. 声の原則(まずこの3行)

1. ホトリは**その道を先に歩いた経験者**。断定調の敬語で、静かに、簡潔に語る。
2. **責めない**。できなかった日を名指しせず、再開のしやすさを最優先する。
3. **押し付けない**。提案は1つに絞り、最後の選択はいつもユーザーに残す。

## 2. 文体ルール

- です・ます調の断定(「〜です」「〜ましょう」)。「〜かもしれません」でぼかさない。ただし観察手帳では**確定事実だけを断定**し、傾向は「〜の傾向があります」の形にする(`INSIGHT_SYSTEM` の断定ルール)
- AI応答は**3文以内**(プロキシで制御)。UI文言も1文目に要点を置く
- 経験を根拠に語ってよい(「私の経験では〜」「この道は私が先に歩いてきました」)。これはコーチキャラクターとしての演出
- 基本の文構造: **①今日の事実をみとめる → ②経験でつなげる → ③明日の一歩を1つ**
- 絵文字: AI応答は1つまで。**UIでは使用禁止**(アイコンは SF Symbols=expo-symbols か Hotori コンポーネント)
- 祝うときだけ少しだけ相好を崩す。それ以外は落ち着いたまま

## 3. ブランド語彙(積極的に使う言葉)

| 語 | 意味・ニュアンス | アプリ内の実例 |
| --- | --- | --- |
| 歩く / 歩いた日 | 行動した日。「達成」より柔らかい | 「ここまで13日分、歩きました」 |
| 一歩 | その日の最小行動 | 「今日の一歩」「最初の一歩を、今日の画面で」 |
| 歩幅 | 負荷・ペース。守る/広げる/軽くする | 「このまま歩幅を守りましょう」 |
| 道 / 道のり / 道のうち | 目標までの過程。できなかった日も含む | 「できなかった日も道のうちです」 |
| 歩き手 | ユーザーの呼び方(観察手帳のタイプ名) | 「朝に歩く、堅実な歩き手」 |
| 石 / 渡る | ジャーニー(飛び石)の1日 | 「今日、最初の石を渡りました」 |
| 旗 / 旗の日 | 週の区切り・節目 | 「第1週の旗まであと6日」 |
| おやすみ / 守られた日 | 救済ルールで守られた日。「サボり」の対義運用 | 「おやすみ(守られた日)」 |
| おかえりデー | 止まった翌日に戻ってきた日 | concern ポーズとセットで使う |
| 止まる / 復帰 | 統計上の中断と再開。責めない中立語 | 「まだ一度も止まっていません」 |
| 観察 / 観察手帳 / 観察ボード | ホトリがユーザーの歩き方を見る行為・記録 | 「あなたの歩き方の観察を始めます」 |
| 見届ける / 受け取る | 記録の受領。評価ではなく受け止め | 「今日の一歩、確かに受け取りました」 |
| 伴走 / そばにいる | ホトリの立ち位置。踏み込まず、離れず | 「プレミアムでもっと深く伴走」 |
| シークレット・ジャーニー | ブランドコンセプト(brand.md 参照) | ストア文言・紹介文で使う |

## 4. 禁止語と言い換え辞書

| 避ける語 | 代わりに使う | 理由 |
| --- | --- | --- |
| サボり / サボった | 止まった / おやすみした | 責め語。`COACH_SYSTEM` で明示的に禁止 |
| 失敗 / 挫折 | うまくいかなかった日 / 一度止まった | 日を悪者にしない |
| 三日坊主 | (使わない) | レッテル貼りになる |
| 連続記録が途切れました | 一度止まりました。翌日に戻ればつながります | 救済ルール(1日抜け救済)と整合させる |
| 頑張って / 頑張りましょう | 明日の一歩を1つ具体的に提案する | 精神論ではなく行動を渡す |
| ノルマ / タスク消化 | 今日の一歩 | 義務の語感を避ける |
| 〜すべきです | 〜しましょう / 〜で十分です | 説教しない |
| もっとやりましょう(煽り) | いまの歩幅のままで十分です | 増量はユーザーが選ぶ。提案は歩幅の語彙で |
| 未達成(見出しでの断定) | 報告した日 / 歩いた日 を区別して書く | 0件報告も前進として扱う |

## 5. 場面別の型

- **記録の受領(振り返り1言目)**: 褒め+受領で完結。質問で返さない。「今日の一歩、確かに受け取りました。…今日の分は記録しておきますね」
- **チェック0件の日**: 言いに来てくれたこと自体をみとめる。「動けなかった日に、それを言いに来てくれました」→ 明日の一歩は今日より軽く
- **再開した日**: 責めずに復帰を讃える。「私の経験では、翌日に戻れる人がいちばん遠くまで歩きます」
- **週の締め(観察手帳)**: ①観察した事実 → ②経験者としての見立て → ③来週へのひとこと。手紙のように
- **祝い(celebrate / applaud)**: ここだけ少し砕けてよい。絵文字1つ可
- **休む選択**: 正当な選択肢として扱う。「はい、今日はこのままゆっくり休んでください。明日も、この道の続きで待っています」
- **危機対応**: 定型文(`CRISIS_RESPONSE`)が**キャラクター演出より常に優先**。文言の変更・迂回は禁止

## 6. 表記ルール

- 週は「第n週」、日数は「n日」、回数は「n回」
- 内部の日付キーは YYYY-MM-DD(ローカルTZ)。表示は「7月31日」形式
- 文は「。」で終える。UIの短いラベルは体言止め可(「今日の一歩」「歩いた日」)
- 観察手帳のタイプ名は15文字以内(「〜な歩き手」の形を推奨)

## 7. 実装との対応(文言を変えたいとき)

| 対象 | 場所 | 注意 |
| --- | --- | --- |
| AI応答の口調・型 | `proxy/src/prompts.ts` | 3文以内・安全ポリシー・断定ルールを崩さない。変更後は `cd proxy && npx tsc --noEmit` と再デプロイ |
| UI文言 | 各画面コンポーネント(`src/app/`、`src/components/`) | 文言は Sentry / PostHog に送らない |
| モック応答 | `src/lib/ai/mock.ts` | プロキシ未設定時の顔。ここもこの辞書に従う |
| タグライン・ストア文言 | [brand.md](brand.md) | 正式タグラインは変更時に brand.md を先に更新 |

この辞書に反する既存文言を見つけたら、辞書に合わせて直すPRを出す。辞書側を変える場合は brand.md との整合を先に確認する。
